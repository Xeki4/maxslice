# maxslice

Поиск максимального значения в большом массиве данных с использованием многопоточности (Go).

## Функции

- `generateRandomElements(size int) []int` — генерация слайса случайных положительных целых чисел.
- `maximum(elements []int) int` — поиск максимума в одном потоке.
- `maxChunks(elements []int) int` — поиск максимума, разбивая слайс на 8 частей и ища максимум в каждой в отдельной горутине (`sync.WaitGroup`).

## Запуск

```bash
go run .
```

## Тесты

```bash
go test -v ./...
```

## Результат

На слайсе из 10 000 000 элементов многопоточный вариант работает быстрее однопоточного, при этом результаты совпадают.
